🛠️ Troubleshooting Guide

1. Cannot Connect to MCP Server (HTTP 502 / Connection Refused)

Ensure the CareLoop server is running on port 8000 using the isolated demo database:
python scripts/run_demo.py or python -m careloop.server --clock simulated

2. Browser Speech Recognition (Voice Input) Inactive

Web Speech Recognition requires HTTPS or localhost / 127.0.0.1. If using Chrome, ensure microphone permission is granted. On Firefox or Safari where SpeechRecognition is unavailable, use the text input box or the quick-action speech bubbles.

3. HTTP 401 Unauthorized / Token Mismatch

In development mode, CareLoop allows open access by default. If an ALEXA_AUTH_TOKEN was set on the server, click the Alexa+ Auth button in the top bar and enter the corresponding bearer token.

4. Resetting Stale or Unexpected Escalation State

Click ↺ Reset Demo Session in the top status bar. This invokes /api/demo/reset to clear simulated events and active alerts while preserving all learned multi-day baseline profiles.

5. Streamable HTTP Transport (/mcp) Errors

Ensure no proxy or VPN is stripping Server-Sent Events headers (text/event-stream). Direct browser access to http://127.0.0.1:8000/simulator uses Starlette HTTP endpoints directly.
